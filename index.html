Kiwi Browser is broken!

This page demonstrates how broken Kiwi Browser is. Kiwi Browser was discontinued in January 2025, at version 132.0.6961.0. Kiwi's major version numbers match those of Chromium.

However, it turns out that Kiwi Browser lacks many features introduced in Chromium versions 117 through 132. This means it's been outdated since September 2023!

Kiwi 137.0.7337.0 was released on 7 April 2025, despite the latest stable Chrome version still being 135.0.7049.38. I therefore plan to include features from Chromium versions 133 through 137 on this page too.

Unless otherwise specified, features explicitly demonstrated on this page are not supported by Kiwi (even 137).
